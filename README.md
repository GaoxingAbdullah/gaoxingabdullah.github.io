# Academic Theme
This is academic theme template built with HTML and CSS. It is designed to be simple, clean, and easy to customize. The template includes sections for research interests, publications, teaching, and a blog. It is responsive and works well on both desktop and mobile devices.

## Customization
To customize the template, you can edit the `index.html` file and the `assets/css/style.css` file. The `index.html` file contains the structure of the page, while the `style.css` file contains the styles for the page. You can change the colors, fonts, and layout of the page by editing the CSS file. You can also add your own content to the `index.html` file, such as your research interests, publications, teaching experience, and blog posts.


## Usage
To use the template, simply download the files and open the `index.html` file in your web browser. You can then customize the content and styles as needed. You can also host the files on a web server to make your academic profile accessible online.
